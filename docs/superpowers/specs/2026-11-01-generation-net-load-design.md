# 发电图与计划/实际净负荷展示设计

## 意图

改善发电图的可读性，并把负荷、实际风光、储能和任务执行时移放到可比较的时间轴上。外网购电作为普通供电构成加入，不做视觉突出；储能先保持现有调度逻辑，避免仅为让图形更丰富而人为增加动作。

## 目标

- 发电堆叠图增加外网购电项（已有数据字段 `grid_import_mw`，统一接入实时/汇总图）。
- 将发电图的高饱和颜色改为低饱和蓝灰、青灰、暖灰配色。
- 发电图同一时间轴展示：负荷曲线、实际风电/光伏堆叠、储能出力（正放电、负充电）以及外网购电项。
- 新增任务功率曲线：按任务提交时间和计划时长展开的“计划任务功率”，以及按实际开始/结束时间展开的“实际执行任务功率”。主图使用 MW，以便与能源图直接对照；同步提供计划/实际算力字段用于核对。
- 第一版不把计划风光并入计划出力净负荷；风光只以实际出力参与供给侧展示。图中“负荷”仍保持现有电网侧实际负荷口径。

## 非目标与约束

- 不修改储能优化目标、SOC 约束或调度权重；储能使用率变化应由现有策略和新展示口径反映出来。
- 不把图中的负荷减去风光/储能直接宣称为严格的实时电网购电需求；它是用于观察削峰填谷效果的可视化分解。
- 保持现有 API 字段兼容，新增字段缺失时前端回退为 0。

## 实现方式

采用后端生成派生字段、前端统一绘制的方式。后端沿用当前统计记录和 300 秒汇总流程：根据任务的计划时间窗与实际执行时间窗，分别累计计划/实际任务功率和算力；新增字段进入长周期聚合。前端复用现有 SVG 图表组件，扩展供给/负荷/储能图与任务功率对比图，并替换发电图颜色。

## 验收

- 发电图图例出现“外部电网购电”。
- 发电图整体颜色明显降低饱和度，储能颜色不再使用高亮紫/绿组合。
- 同一时间轴可同时看到负荷、实际风光和储能出力，储能充放电方向清晰可辨。
- 第二张图能同时看到计划任务功率与实际执行任务功率，延迟执行时两条曲线的时移可见。
- 现有前端与仿真测试保持通过。
