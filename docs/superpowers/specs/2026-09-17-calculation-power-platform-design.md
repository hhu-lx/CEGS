# 算电协同平台重构设计

## 目标

将现有算电协同仿真项目重构为配置驱动、策略可替换且支持真实 COPT 求解的研究型平台。平台模拟用户主动提交的计算任务如何经由数据中心、电力网络和储能系统形成算力影响电力、电力反馈算力调度的闭环。

## 范围

- 用户通过 FastAPI 主动提交任务；Excel 导入只保留为可选历史数据导入工具。
- IEEE 39 节点 Pandapower 网络接收背景负荷、风光出力、计算负荷以及储能充放电。
- 调度可以使用配置选择的启发式策略，也可由真实 COPT 进行全局优化。
- 所有输入、策略、目标函数和约束均由 YAML 配置选择；缺失任务数据由确定性模拟数据工厂补齐。

## 分层结构

### 领域层

`Task` 表示用户任务，拥有提交时刻、最大等待时长、计算量、执行时长、数据量、CPU/GPU 数量、GPU 类型、地区、状态和取消原因。状态仅可沿 `pending -> ready -> running -> completed` 运行，或由 `pending/ready -> cancelled/rejected` 结束。

`DataCenter` 维护地区、挂载节点、算力、带宽、PUE 和设备池。设备池条目具备型号、数量、单设备算力和单设备功耗。资源校验同时检查算力、带宽、GPU 类型和数量；总功耗等于 IT 功耗乘以 PUE。

`EnergyStorage` 表示挂载电网节点的储能资源，维护能量容量 MWh、功率 MW、SOC 边界、初始 SOC、充放电效率、循环成本和当前状态。储能不是普通发电机：充电是节点负荷，放电是节点电源注入。

### 策略层

策略注册表按配置创建五类可替换规则：任务分配、算力定价、算力到功耗映射、电价计算和优化目标函数。预置分配策略包括最低价、低碳、延迟感知和负载均衡。预置目标包括最小成本、最小碳排、最小延迟和加权目标；用户自定义目标以实现受控目标函数接口并通过注册名配置的方式接入，不执行任意 YAML 表达式。

### 仿真层

仿真时钟支持毫秒、秒、分钟和小时的配置化时间单位。每一步按以下顺序执行：

1. 更新背景负荷、光伏和风电时序数据。
2. 释放已到达任务，并取消超过最大等待时长的任务。
3. 根据上一轮潮流状态更新节点电价、节点碳强度和数据中心算力报价。
4. 通过启发式策略或启用的 COPT 优化器为就绪任务决策。
5. 启动获得资源的任务，注入其经 PUE 修正的计算负荷。
6. 执行储能策略或优化结果，注入储能充放电功率。
7. 执行潮流，采集节点电压、线路潮流、节点电价、节点碳强度和发电机出力。
8. 记录任务、电网、碳排、储能和优化统计，供下一步决策与 API 查询。

### 优化层

真实 COPT 通过 `coptpy` 集成。优化器建立任务—数据中心二元分配、发电机出力、储能充放电功率、SOC 和任务延迟变量，并实现功率平衡、机组出力上下限、数据中心算力/带宽/设备、任务等待、储能 SOC 平衡及禁止同时充放电等约束。可按配置增加碳上限、线路容量和节点电压约束。

优化结果包含求解状态、目标值、任务分配、机组出力和储能计划。COPT 导入、许可证、模型不可行和求解超时均为显式错误状态；仅在配置关闭优化器时才使用启发式调度。

### 基础设施、数据与接口层

Pandapower 适配器提供一份统一的电网快照，其中包括各节点电压、线路有功/无功潮流、总负荷、总发电、节点电价、节点碳强度、按发电类型的排放贡献和电压稳定指标。

YAML 是唯一运行配置入口，包含时间粒度和时长、时序数据、数据中心、储能、策略、优化开关、目标与约束。任务缺失的数据量、CPU/GPU 与设备要求只由带固定随机种子的 `SyntheticTaskDataFactory` 补齐，且种子写入运行结果。

FastAPI 提供任务提交和状态查询、最新/历史电网状态、碳排统计、储能状态及优化结果查询。请求参数错误返回清晰的 4xx 响应。

## 数据与单位

- 任务计算量使用 TFLOPS·h；执行时长用于推导瞬时算力。
- 功率使用 MW，能量使用 MWh，节点电价使用元/kWh，碳强度使用 kgCO2/kWh。
- 时序负荷、光伏和风电输入为 pu，并以基准容量换算为 MW。
- 储能 SOC 以 MWh 保存，充放电效率在 SOC 转换时应用。

## 质量与验证

采用测试先行实现。测试覆盖任务生命周期、模拟数据补齐、配置策略选择、PUE 与设备资源、储能 SOC/充放电约束、COPT 小规模模型求解、报价反馈闭环以及 FastAPI 合约。交付项目依赖声明、示例配置、示例模拟数据与使用说明；不修改现有原始 Excel 和 CSV 数据。
