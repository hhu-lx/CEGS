# 浅色专业分析风前端仪表盘设计

## 目标

在保留现有配置、仿真控制、实时统计、四类核心曲线、健康状态和数据导出能力的基础上，将前端升级为浅色专业分析风的算电协同运行驾驶舱。页面面向仿真配置、运行监测和结果分析，不改变仿真核心逻辑和现有上传接口。

## 视觉与布局

- 采用 16:9 桌面画布，浅灰白背景、白色信息卡、浅蓝边框和轻阴影。
- 主色为深海军蓝与分析蓝，青绿色表示新能源/正常状态，黄色表示预警，红色表示异常。
- 顶部为平台标题、连接状态和运行时间；其下为总负荷、总发电、碳排放、运行任务、总算力和仿真时长 KPI。
- 页面主体为三栏信息架构：左侧配置与控制，中部实时算电协同总览，右侧健康、资源、任务和告警卡片。
- 底部保留四个分析面板：发电曲线、负荷曲线、各数据中心运行算力堆叠柱状图、算力功率曲线，并保留导出入口。
- 小屏幕下取消固定 16:9 高度，改为单列滚动布局，确保配置项和图表可访问。

## 信息模块

### 左侧配置与控制

保留并增强现有任务文件、用户配置文件、峰谷电价 CSV 上传，调度策略、定价策略、优化模型选择，算力-功率映射只读说明，以及应用配置、启动仿真、结束仿真和重置操作。新增配置来源和当前生效数据中心摘要。

### 顶部运行指标

继续使用现有状态接口返回的总负荷、总发电、碳排放、运行任务和仿真时间；总算力从实时统计中的数据中心运行算力分布求和。指标无数据时显示零值，不伪造后端数据。

### 中部运行总览

增加轻量级 SVG/CSS 示意：电网位于中心，风电、光伏、常规电源、储能和三个数据中心作为节点，以图例区分电力流、算力任务流和数据流。示意图只表达当前平台拓扑关系，不替代真实潮流图。

### 右侧监测卡片

- 电网健康：潮流状态、电压状态、线路状态和电网健康指数；没有对应后端指标时显示“暂无数据”或保留现有状态文本。
- 数据中心资源：展示各中心算力、功率、任务数或利用率；使用实时统计和已生效数据中心配置，缺失字段采用明确的“—”。
- 任务队列：展示提交、排队、运行、完成、取消数量。
- 实时告警：根据已有运行状态或健康状态生成提示，不引入新的告警规则；无告警时显示“暂无告警”。

### 底部图表

- 发电与负荷继续使用现有实时历史数据。
- 任务图使用每个统计时刻一个柱子的堆叠柱状图，颜色代表数据中心，区段高度为该中心当前运行任务的算力总和，柱高为全部运行算力总和。
- 算力功率继续使用预定义算力-功率映射的统计结果。
- 图表保持无第三方运行时依赖，使用现有内嵌 SVG 绘制方式。

## 数据边界

- 后端仅补充前端需要的展示字段，不改变任务调度、优化和电网计算逻辑。
- 实时统计按当前配置的高频统计间隔更新，前端按约 1 秒轮询状态并按 `second` 去重历史点。
- 所有新增卡片允许缺失数据，不能用随机值或静态示例值覆盖真实结果。
- 导出格式和导出接口保持不变。

## 验证

- 保留并运行现有 Python 测试。
- 增加前端静态检查：模块标题、浅色主题类名、资源/告警容器和新图表函数存在。
- 使用 Node 进行 `app.js` 语法检查。
- 启动服务后检查首页、配置提交、实时状态刷新和导出入口不被破坏。
