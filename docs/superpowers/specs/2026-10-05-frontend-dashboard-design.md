# 算电协同仿真平台前端设计

## 目标

为现有算电协同仿真平台增加一个可直接使用的中文桌面端 Web 页面，使用户能够上传任务和用户配置、导入峰谷电价 CSV、选择调度/定价/优化策略、应用配置、启动或结束仿真，并查看四类结果曲线、电网健康状态和关键指标。

## 范围与约束

- 页面作为现有 FastAPI 应用的根页面提供，不引入独立前端构建链。
- 前端使用原生 HTML、CSS 和 JavaScript；不新增 npm 运行时依赖。
- 仿真控制只提供“启动仿真”和“结束仿真”，不提供暂停。
- 发电和负荷时序数据不在前端上传；仅在仿真结果中绘制曲线。
- 峰谷电价通过 CSV 文件导入，CSV 至少包含时段与价格信息，由后端校验。
- 用户配置数据支持 YAML/YML/JSON；后端负责解析、合并和资源校验。
- 调度策略、定价策略和优化模型是用户可选项；算力-功率映射显示为只读预定义策略，不提交编辑值。
- 结果区只展示发电曲线、负荷曲线、任务统计和算力功率曲线四类图表。

## 页面结构

### 左侧配置区

1. 仿真控制：显示当前状态和仿真时间；提供启动与结束按钮。
2. 电力拓扑：选择当前拓扑并显示加载状态。
3. 任务数据：上传 CSV/XLSX/JSON 任务文件。
4. 用户配置数据：上传 YAML/YML/JSON 配置文件。
5. 峰谷电价：上传 CSV，显示“待导入/已导入/校验失败”。
6. 协同方式：
   - 调度策略：最低价格、低碳优先、延迟优先、负载均衡、自定义；
   - 定价策略：分时电价、边际电价、自定义；
   - 优化模型：启发式、局部优化、全局优化；
   - 算力-功率映射：只读“预定义：线性映射”。
7. 应用配置：提交并校验当前页面配置。

### 右侧结果区

- 电网健康状态：潮流收敛、电压越限、线路拥塞三个状态项。
- KPI：总负荷、总发电、碳排放、运行任务。
- 四张结果图：发电曲线、负荷曲线、任务统计、算力功率曲线。
- 数据导出：下载 CSV/Excel/JSON 可用结果。

## API 设计

### 页面与静态资源

- `GET /`：返回 `src/web/index.html`。
- `GET /static/...`：返回 CSS、JavaScript 等静态资源。

### 配置与控制

- `POST /config/apply`：接收 multipart 表单，包括策略字段、任务文件、用户配置文件和峰谷电价 CSV；校验通过后写入当前应用会话配置，返回配置摘要。
- `POST /simulation/start`：使用已应用配置启动或重建仿真引擎，返回运行状态。
- `POST /simulation/stop`：停止当前仿真，返回结束状态。
- `GET /simulation/status`：返回运行状态、仿真时间、最新统计和健康状态。
- `GET /export`：返回当前运行的统计 CSV、任务执行 CSV 与配置快照的下载包，并支持 `format=csv|xlsx|json`。

已有接口继续复用：`/tasks`、`/grid/latest`、`/carbon/summary`、`/storage`、`/optimization/latest`、`/pricing`。

## 状态与错误处理

- 页面初始状态为“未运行”。
- 应用配置前，启动按钮不可用；配置成功后才允许启动。
- 启动后前端每 2 秒请求一次状态；结束或请求失败时停止轮询。
- 文件格式、字段缺失、配置资源不足和仿真未配置统一显示为可读的错误提示，不吞掉后端错误详情。
- 结束仿真后保留图表和最后一次 KPI，允许导出。

## 测试与验收

- API 测试覆盖页面响应、配置上传校验、启动/结束状态、状态查询和导出响应。
- 前端静态检查确认四张图、只读映射、三个策略选择组和上传入口存在。
- 运行现有 Python 测试集，确保没有破坏任务、价格和仿真逻辑。
- 手动启动 FastAPI，打开根页面，完成一次配置应用和启动/结束流程。
